# 板块分类框架

做行业基本面分析，第一步不是选板块，而是**选定一套互斥且穷尽的分类骨架**。国内常见三套体系，适用场景不同，不要混用。

## 一、三套主流分类对比

| 体系 | 层级 | 一级数量 | 归类逻辑 | 适用场景 | 局限 |
|---|---|---|---|---|---|
| **申万行业分类**（SWS，2021 版） | 一级 / 二级 / 三级 | **31 / 134 / 346** | 以主营收入构成为主，贴近 A 股实际收入结构 | **A 股基本面研究的事实标准**，绝大多数卖方研报、Wind 行业指标、指数（申万一级行业指数）都基于它 | 对跨行业公司归类有时生硬；不反映主题 |
| **中信行业分类**（CITICS，2020 版） | 一级 / 二级 / 三级 | **30 / 109 / 300+** | 类似申万，细节归口不同 | 部分券商内部、中信系研究 | 与申万二级口径差异大，混用会导致统计口径断裂 |
| **GICS**（MSCI + S&P，2023 版） | Sector / Industry Group / Industry / Sub-Industry | **11 / 25 / 74 / 163** | 全球可比，按业务性质 | 外资持仓分析、跨市场（A/H/美股）对比、指数化投资 | 颗粒度粗，A 股特色板块（如"电力设备"）被拆散 |

**补充（不作基本面骨架，仅作事件跟踪）：**
- 东方财富 / 同花顺**概念板块**：数量数百个，成分重叠、动态调整、无稳定口径 → 只适合跟踪主题与资金流，**不能用来算行业盈利和估值分位**。
- 证监会行业分类、国民经济行业分类（GB/T 4754）：统计口径，用于对宏观数据。

## 二、本项目为什么以「申万一级」为骨架

1. **数据可得性最好**：Wind / Choice / 东财 / 同花顺均直接提供申万一级行业指数、成分、估值分位。
2. **与卖方研究同构**：行业深度报告、盈利预测汇总基本按申万一级组织，便于交叉验证。
3. **颗粒度适中**：31 个板块，一个人一年可以覆盖完；再细到 134 个二级则精力不够。

**规则：一级做"地图"，二级做"手术刀"。** 只有当某个一级板块内部基本面分化极大时（典型：医药生物、电力设备、有色金属、机械设备），才下钻到二级。

## 三、31 个一级板块的四种属性分组

做基本面分析时，驱动变量按属性分成四类，判断方法完全不同：

| 属性 | 板块 | 核心分析逻辑 | 主导变量 |
|---|---|---|---|
| **强周期**（看价格与库存） | 煤炭、石油石化、有色金属、钢铁、基础化工、建筑材料 | 供需缺口 → 价格 → 利润弹性；**跟踪价格和库存比跟踪收入更重要** | 商品价格、开工率、库存天数、产能投放 |
| **弱周期 / 消费**（看量与价、看渠道） | 食品饮料、家用电器、纺织服饰、轻工制造、商贸零售、社会服务、美容护理、农林牧渔、医药生物 | 需求韧性 + 提价能力 + 渠道库存；**看量价拆分、看渠道健康度** | 社零、批价、同店、库存周转 |
| **金融 / 类金融**（看资产负债表） | 银行、非银金融、房地产 | 利润由**资产负债表结构与利差**决定，不看毛利率 | 净息差、不良率、成交额、销售面积 |
| **成长 / 制造**（看渗透率与资本开支） | 电子、电力设备、汽车、机械设备、国防军工、计算机、通信、传媒、公用事业、交通运输、环保、建筑装饰、综合 | 渗透率曲线 + 产能周期 + 政策；**看订单/排产领先指标** | 出货量、招标量、capex、渗透率 |

> 注意：**同一板块在不同阶段会换属性**。例如汽车 2015 年是成长股（渗透率提升），2023 年后价格战中转成类周期；电力设备 2020 年是成长，2023 年产能过剩后变成周期。属性判断错了，估值方法就会用错。

## 四、概念板块的正确用法

- ❌ 不用概念板块算行业盈利、ROE、PE 分位。
- ✅ 用概念板块做：主题催化跟踪（政策发布、技术突破）、资金流向、龙头识别。
- ✅ 概念 → 落到申万二级，才能做基本面验证。
