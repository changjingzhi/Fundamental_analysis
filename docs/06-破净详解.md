# 破净详解：PB < 1 到底意味着什么

> 分析日期：2026-11-16
> 前置阅读：[`04-PE与PB详解.md`](./04-PE与PB详解.md)（PB 的定义与陷阱）、[`05-ROE详解.md`](./05-ROE详解.md)（ROE 与 PB 的关系）

---

## 0. 一句话

> **破净（PB < 1）= 市值低于账面净资产 = 市场在说「这堆资产不值账面上标的那个数」。**

$$\text{PB} < 1 \quad \Longleftrightarrow \quad \text{每股股价} < \text{每股净资产}$$

**但「市场为什么不认这个账面价值」，才是真正的问题。**

---

## 1. 三个常见误解，先破掉

| 误解 | 真相 |
|---|---|
| ❌ 破净 = 便宜 | 破净只说明「价格低于账面价值」，不说明「值得买」 |
| ❌ 破净 = 清算价值 | 清算时存货要打折、设备要贱卖、应收要坏账，实际能拿回的远低于账面 |
| ❌ 破净 = 有安全边际 | 如果净资产本身会继续减值，那安全边际是假的 |

> **破净不是结论，是一个需要解释的现象。**

---

## 2. 破净在数学上意味着什么（核心）

在零增长假设下，PB 与 ROE 的关系是：

$$\text{PB} = \frac{\text{ROE}}{r} \qquad (r = \text{市场要求回报率})$$

**所以：**

| 情形 | 含义 |
|---|---|
| **ROE > r** | PB > 1，市场愿意溢价 |
| **ROE = r** | PB = 1，市场认为刚好值这个钱 |
| **ROE < r** | **PB < 1，破净** ← 资本在被低效使用 |

**换句话说：破净的本质是「这家公司用股东的钱赚不到市场要求的那个回报率」。**

### 2.1 用真实数据验证（✅ 2026-11-16）

用恒等式 $\text{ROE} \approx \text{PB} / \text{PE}$ 反推：

| 公司 | 行业 | PB | PE | **反推 ROE** | 是否破净 |
|---|---|---|---|---|---|
| 保利发展 | 地产 | **0.32** | 20.17 | **约 1.6%** | 🔴 破净 |
| 万科 A | 地产 | **0.39** | **-1.12（亏损）** | **负** | 🔴 破净 |
| 中国建筑 | 建筑 | **0.39** | 5.04 | 约 7.7% | 🔴 破净 |
| 鞍钢股份 | 钢铁 | **0.44** | **-3.27（亏损）** | **负** | 🔴 破净 |
| 海螺水泥 | 建材 | **0.51** | 26.52 | 约 1.9% | 🔴 破净 |
| 宝钢股份 | 钢铁 | **0.66** | 15.15 | 约 4.4% | 🔴 破净 |
| 工商银行 | 银行 | **0.82** | 8.47 | 约 9.7% | 🔴 破净 |
| 中国石化 | 石油石化 | **0.84** | 13.56 | 约 6.2% | 🔴 破净 |
| 中信证券 | 非银 | 1.24 | 9.52 | 约 13.0% | 🟢 不破净 |
| 中国神华 | 煤炭 | **2.47** | 18.56 | 约 13.3% | 🟢 不破净 |

> 🔑 **看这张表：破净与不破净的分界线，几乎正好落在 ROE ≈ 10%。**
>
> - ROE < 10% 的，全部破净
> - ROE > 13% 的，全部不破净（神华甚至给到 2.47 倍）
>
> **这就是「PB = ROE / r」的实证：市场对重资产行业的要求回报率大约就是 10%。**

### 2.2 一个极端的对照

| | 中国神华 | 保利发展 |
|---|---|---|
| PB | **2.47** | **0.32** |
| 反推 ROE | 13.3% | **1.6%** |
| 市场含义 | 「这生意赚钱，值得溢价买」 | 「这堆资产在持续贬值」 |

**两者差了 7.7 倍 —— 但都是重资产公司。差别不在「资产多不多」，在「资产能不能赚钱」。**

## 3. 为什么会破净：五个原因

| # | 原因 | 机制 | 典型行业 |
|---|---|---|---|
| **1** | **ROE 低于资本成本** | 赚得不如存银行/买国债 | 钢铁、建筑、部分银行 |
| **2** | **资产质量存疑** | 账面净资产虚高（不良、存货、应收、商誉） | 银行、地产 |
| **3** | **行业生命周期见顶** | 需求不可逆萎缩，资产只会越来越不值钱 | 地产、传统建材、传统传媒 |
| **4** | **治理与分红缺陷** | 现金再多也不分给股东，账面价值和股东无关 | 部分国企、多元化集团 |
| **5** | **市场情绪与流动性** | 缺乏资金关注，估值长期压制 | 小市值、冷门行业 |

> ⚠️ **第 1、2 条是「基本面破净」，第 3 条是「结构性破净」，第 4、5 条是「可修复的破净」。**
> **同样是 0.4 倍 PB，可能是金子，也可能是刀子 —— 区别就在原因。**

---

## 4. 破净股的三类机会

### A. 周期性破净 → 可能是机会 ✅

**特征**：行业处在周期底部，资产是真实的，ROE 暂时被压低。
**例子**：钢铁、水泥、化工龙头在景气底部时 PB 0.5–0.7。
**逻辑**：一旦景气反转，ROE 回升 → PB 修复 → **双击**。
**风险**：如果周期不来，会一直趴着。

### B. 结构性破净 → 通常是陷阱 ❌

**特征**：行业需求永久性萎缩，资产（尤其存货、专用设备）会持续减值。
**例子**：地产开发（土地存货贬值）、传统零售（门店价值下降）。
**逻辑**：**PB 会「一边跌一边变贵」** —— 因为分母（净资产）也在缩水。
**风险**：万科 PB 0.39 看着便宜，但 PE 是 -1.12（在亏损）。

### C. 治理性破净 → 需要催化剂 ⏳

**特征**：资产质量好、现金充裕，但长期不分红、不回购、不做市值管理。
**例子**：部分地方国企、控股型集团。
**逻辑**：一旦出现分红提升、资产注入、国企改革等催化，估值会快速修复。
**风险**：**催化剂不来，就一直破净**（A 股很多公司破净十年）。

## 5. 判断破净真假的六步检查

| 步骤 | 查什么 | 危险信号 |
|---|---|---|
| **① 净资产构成** | 现金 / 存货 / 应收 / 固定资产 / 商誉 各占比 | 存货或应收占比过高、商誉占比 > 20% |
| **② 减值是否充分** | 近三年计提了多少减值准备 | 减值计提远低于同业 → 还有雷没爆 |
| **③ ROE 趋势** | 过去 5 年 ROE 轨迹 | 单边下行 → 结构性衰退 |
| **④ 分红能力** | 分红率、股息率、账上现金 | 有现金但不分红 → 治理问题 |
| **⑤ 行业需求** | 营收 5 年趋势、渗透率 | 连续下滑 → 结构性破净 |
| **⑥ 催化剂** | 有没有改革、重组、注入、回购计划 | 完全没有 → 只能等 |

> 🔑 **六步里最重要的是第 ③ 步：ROE 是在回升还是在单边下行。**
> 这决定了你买的是「周期底部的金子」还是「价值陷阱的刀子」。

## 6. 破净率：一个有用的情绪指标

### 6.1 板块破净率（✅ 真实数据）

| 板块 | 破净情况 | 含义 |
|---|---|---|
| **银行（42 家上市银行）** | **42 / 42 = 100%** | 全行业悲观定价，无一例外 |
| **煤炭（9 家龙头样本）** | 焦煤 4 家破净（潞安 0.84、平煤 0.85、淮北 0.92、山西焦煤 0.96）<br>动力煤 0 家破净（神华 2.47、陕煤 2.51） | **板块内部严重分层** |
| 地产 / 建筑 / 钢铁 / 建材 | 典型标的普遍 0.3–0.7 | 需求下行行业集中破净 |

### 6.2 破净率的正确用法

| ✅ 可以这样用 | ❌ 不要这样用 |
|---|---|
| 衡量板块的**悲观程度** | 当作「马上要涨」的信号 |
| 判断**预期是否已充分反映** | 当作买入理由 |
| 对比**历史极值**判断极端程度 | 跨行业比较破净率高低 |

> ⚠️ **破净率高≠见底。** A 股很多板块破净率 50% 以上还能再破净三年。
> **破净率只说明「大家的预期很低」，不说明「预期一定会修复」。**

### 6.3 一个反例：煤炭板块的内部分层

**同一个申万一级行业，动力煤 PB 2.47、焦煤 PB 0.84 —— 差 3 倍。**

原因不是「焦煤资产差」，而是：
- 动力煤：长协定价 → 盈利稳定 → 可预测 → **市场愿意给高 PB**
- 焦煤：纯市场化 → 盈利波动 70%+ → **市场不敢给高 PB**

**这就是破净的真相：市场在给「盈利的确定性」定价，不是在给「资产多少」定价。**

## 7. 破净股的三个操作要点

| 要点 | 说明 |
|---|---|
| **1. 先分类，再判断** | 周期性 / 结构性 / 治理性 —— 三类机会完全不同 |
| **2. 用「净资产减值后」算真实 PB** | 把可疑资产打折后重算，例如银行不良未充分暴露时真实 PB 会显著高于账面 |
| **3. 必须有催化剂** | 破净股不会自己修复，需要景气反转 / 分红提升 / 重组 / 回购中的至少一个 |

> 📘 **假设示例：** 某银行账面 PB 0.45，但不良率被低估、拨备不足。
> 把 30% 的净资产视为「未来要减值」，则真实 PB ≈ 0.64。
> **这就是 [`04-PE与PB详解.md`](./04-PE与PB详解.md) 第 2.4 节「价值陷阱」的算法。**

## 9. 一页速查

```
破净 = PB < 1 = 市值 < 账面净资产

数学本质：
PB = ROE / r   →  ROE < r 就破净
市场对重资产行业的要求回报率 ≈ 10%
→ ROE < 10% 大概率破净（已用 10 家真实公司验证）

破净的五个原因：
1. ROE 低于资本成本
2. 资产质量存疑（不良、存货、应收、商誉）
3. 行业结构性衰退
4. 治理与分红缺陷（有现金不分）
5. 情绪与流动性

三类机会：
A. 周期性破净 → 可能是金子（等景气反转）
B. 结构性破净 → 通常是刀子（越跌越贵）
C. 治理性破净 → 等催化剂（分红/重组/回购）

六步检查：
净资产构成 → 减值充分性 → ROE 趋势 → 分红能力 → 行业需求 → 催化剂

三句话记住：
1. 破净不是便宜，是「市场认为资产不值账面数」
2. PB 低而 PE 高，说明 ROE 极低（保利 PB 0.32 / PE 20.17）
3. 判断依据永远是 ROE 往哪走，不是 PB 有多低
```

> **破净是市场投出的一张「不信任票」。**
> 你要做的不是相信或不相信这张票，而是去查：**这张票投得对不对。**
