# 均值回归型资产怎么买：把「找趋势起点」换成「测量偏离中枢的距离」

> 创建日期：**2026-11-18**
> 起因：上一节 [`09-仓位与持仓结构框架.md`](./09-仓位与持仓结构框架.md) 说红利/类债不该用日线 MACD 卖出，但没有回答「那该用什么买」。**这类资产当然有波动、当然可以低买**——区别只在于「低点」的定义方式完全不同。
> 关联：[`09-仓位与持仓结构框架.md`](./09-仓位与持仓结构框架.md)、[`04-PE与PB详解.md`](./04-PE与PB详解.md)、[`05-ROE详解.md`](./05-ROE详解.md)、[`../screening/2026-11-17/类债资产扫描.md`](../screening/2026-11-17/类债资产扫描.md)、[`../screening/2026-11-17/全历史估值分位.md`](../screening/2026-11-17/全历史估值分位.md)、[`../qa/2026-11-17-为什么波动与周期不同.md`](../qa/2026-11-17-为什么波动与周期不同.md)

## 0. 结论先行

**均值回归型资产的低点，比趋势型更容易判断——因为它有「锚」。**

| | 趋势型（科技/主题） | **均值回归型（红利/类债）** |
|---|---|---|
| 「低点」是什么 | **趋势反转的起点**——不可知 | **偏离中枢的负向极值**——**可测量** |
| 怎么确认 | 只能等突破后用金叉确认（**滞后**） | 用偏离度 / 分位**当场算出来**（**不滞后**） |

$$\text{趋势型：} \ \text{底在哪？} \ \Rightarrow \ \text{不知道，等它自己证明}$$
$$\text{均值回归型：} \ \text{底在哪？} \ \Rightarrow \ \text{知道中枢，量出距离就够了}$$

> **你不需要找「底」，你需要测量「离中枢多远」。** 这是两种完全不同的工作。

## 一、为什么均值回归型有「锚」

### 1.1 中枢可以算出来

$$\frac{P^*}{B} = \text{合理 PB} \approx \frac{\text{ROE} - g}{r - g} \quad \Longrightarrow \quad P^* = \text{合理 PB} \times \text{BPS}$$

- $\text{ROE}$：公司的赚钱能力（可查、可跟踪）
- $r$：市场要求的回报率（由 10Y 国债 + 风险溢价决定）
- $g$：永续增长率（类债资产通常 0%~3%）

**科技股没有这个公式能落地**（$g$ 可能从 0 跳到 100%），**高速、银行、运营商有**（$g$ 就是 GDP 或 0）。

### 1.2 三种锚，按可靠性排序

| 锚 | 具体指标 | 为什么可靠 | 适用标的 |
|---|---|---|---|
| **① 股息锚** | **股息率 − 10Y 国债收益率** | 现金流是真的付出来的，且可与其他无风险资产直接比较 | 银行、高速、港口、运营商 |
| **② 净资产锚** | **PB 全历史分位** | 净资产不受周期影响（对比 PE 的分子 E 会剧烈波动） | 全部类债 + 周期 |
| **③ 盈利锚** | ROE 均值回归 | ROE 的长期中枢比单季利润稳定得多 | 公用事业、燃气 |

### 1.3 ⚠️ 最重要的一条：PB 低 ≠ 便宜

**福建高速就是现成的反例：**

$$\text{PB} = \text{ROE} \times \text{PE} = 6.8\% \times 11.71 = \mathbf{0.80}$$

> `INDEX.md` 里对它的判语是：**「ROE 仅 6.8%，PB 0.80 是恒等式必然；买点看股息率」**。

**PB 0.80 不是「打了八折」，是「ROE 只有 6.8% 的数学结果」。** 真正低的是 ROE，不是价格。

| 组合 | 判定 |
|---|---|
| PB 分位低 **+ ROE 趋势平/升** | ✅ **真便宜**（均值稳定，价格偏离） |
| PB 分位低 **+ ROE 单边下滑** | ❌ **价值陷阱**（地板在下移，你在追一个下沉的中枢） |

$$\text{价值陷阱的数学形式：} \ \text{合理 PB} \downarrow \ \text{的速度} \ > \ \text{实际 PB} \downarrow \ \text{的速度}$$

**所以买入判据永远是「分位 + ROE 趋势」两维，不能只看一维。**

## 二、五类买入信号：锚定方向 + 时机定扣扳机

| # | 类别 | 信号 | 阈值 | 现有数据 |
|---|---|---|---|---|
| **1** | **锚** | **股息率 − 10Y 国债 的利差分位** | **> 80% 分位** | ⚠️ 缺 10Y 序列（`INDEX.md` 列 🔴 最高优先级缺口） |
| **2** | **锚** | **PB 全历史分位**（2018 起） | **< 20% 分位** | ✅ `_全历史分位.py` |
| **3** | 时机 | **250 日均线偏离度** | **(P − MA250)/MA250 < −2σ** | ✅ 日线可算 |
| **4** | 时机 | **RSI(14)** | **< 30** | ✅ 日线可算 |
| **5** | 时机 | **MACD 绿柱连续缩短**（见第三章） | **连续 3 日** | ✅ 你已经在看柱状图 |

### 2.1 组合规则（这是整套方法的操作核心）

$$\boxed{\text{买入} = \underbrace{\text{至少 1 个锚信号}}_{\text{#1 或 #2}} \ \textbf{AND} \ \underbrace{\text{至少 1 个时机信号}}_{\text{#3 / #4 / #5}}}$$

| 只满足锚 | 只满足时机 |
|---|---|
| ❌ **太早**——便宜了还能更便宜，可能等半年 | ❌ **接刀**——在下跌中继里抄底 |

**「锚」告诉你便不便宜，「时机」告诉你抛压是否耗尽。缺任何一个都别动手。**

### 2.2 为什么不用「跌了 X% 就买」

| 资产 | 过去跌幅 | 现在分位 | 意义 |
|---|---|---|---|
| 兆易创新 | 从 244.57 跌到 214.41（**-12.3%**） | PE/PB **双 0 分位** | 跌幅小但**位置极低** → 好机会 |
| 利通电子 | 曾单月 **+126%** | PE 分位 **0%** 但 PB 分位 **90.5%** | 涨了很多却"PE 最低" → **陷阱** |

**跌幅是相对过去，分位是相对历史定价区间。两者经常背离，所以只能用分位。**

## 三、MACD 的正确用法：把它**反着用**

你已经会看「红柱顶点」。均值回归型资产的买点，就是它的**镜像**：

$$\text{趋势型买点（C 层）} = \text{零轴附近/上方金叉，红柱持续增长}$$
$$\boxed{\text{均值回归型买点（A 层）} = \text{零轴下方深处，绿柱连续缩短}}$$

### 3.1 一张表看清「同一张柱状图，方向相反」

| 维度 | 趋势型（科技/主题） | **均值回归型（红利/类债）** |
|---|---|---|
| 看哪个柱 | 红柱（上涨动能） | **绿柱（下跌动能）** |
| 买点信号 | 红柱**开始增长** | **绿柱开始缩短** |
| 卖点信号 | 红柱**开始缩短** | 绿柱**开始增长**（且分位高） |
| DIF 位置 | ✅ 零轴**上方** | ✅ 零轴**下方深处** |
| 金叉含义 | **买入** | ⚠️ 不要急——等回调后再金叉才有效 |
| 死叉含义 | **卖出** | ⚠️ **不是卖出信号**，是「观察绿柱何时缩短」 |
| 本质 | **顺势追涨** | **逆势抄衰竭** |

### 3.2 为什么「绿柱缩短」在这类资产上更可靠

$$\text{MACD 柱} = \text{DIF} - \text{DEA}$$

银行日均波动只有 **0.96%**，绿柱缩短通常对应「卖压已耗尽、价格在 MA 附近横住」。而这类资产**下跌有股息和净资产托底，横住之后大概率向上回归**——方向是可预期的。

**对比科技股**：绿柱缩短后可能只是下跌中继（波动 4.79%/天，一次小反弹就重新砸下去）。所以：

| 资产 | 绿柱缩短的可信度 |
|---|---|
| 中证银行（15.1%） | **高**（回归方向明确） |
| 福建高速（31.9%） | 中 |
| 兆易创新（75.7%） | **低**（需配合突破确认） |

### 3.3 但必须加一条硬约束

$$\text{绿柱谷底} \ \textbf{AND} \ \text{估值分位低} \ = \ \text{买点}$$
$$\text{绿柱谷底} \ \textbf{AND} \ \text{估值分位高} \ = \ \text{下跌中继，不买}$$

**你已有的看柱技能可以直接迁移过来，只是把「越短越该卖」换成「越短越该买」，并加上「必须在零轴下方 + 分位低」。**

## 四、仓位：金字塔分档，绝不一把梭

### 4.1 为什么不能一次性买

- 你不知道底在哪（**没人知道**）
- 但你知道「越跌越便宜」（**因为有锚**）→ 这就是可以分档的数学基础

$$\text{不知道底} + \text{知道越跌越便宜} \ \Longrightarrow \ \text{唯一正确做法是「分批」}$$

### 4.2 三档金字塔

| 档 | 触发条件 | 投入（占目标仓位） |
|---|---|---|
| **第 1 档** | PB 分位 **< 20%** 且 股息利差分位 **> 70%** | **30%** |
| **第 2 档** | PB 分位 **< 10%** 且 股息利差分位 **> 85%** | **30%** |
| **第 3 档** | PB 分位 **< 5%** 且 股息利差分位 **> 95%** | **40%** |

**关键：用「分位档」触发，不用「价格跌幅」触发。**

原因：价格跌幅是绝对值，分位是相对值。如果 ROE 下滑导致中枢下移，分位会**自动调整**，而「跌了 20% 就买」会在新的地板上买在半山腰。

### 4.3 总仓位上限仍然受 09 文档约束

$$\text{A 层总权重} \le 45\%, \qquad \text{单只} \le 15\%$$

**不管跌多少，上限不动。** 这是防止「越跌越买」演变成「重仓被套」的唯一保险。

## 五、卖出：对称的「上沿」逻辑（慢）

| 信号 | 动作 |
|---|---|
| 股息利差 < **20%** 分位 | 减 1/3 |
| PB 分位 > **80%** | 减 1/3 |
| 偏离 **+2σ** 或 RSI > 70 | 减 1/3 |
| **基本面证伪**（见第六章） | **清仓** |

### 5.1 一个必须知道的非对称性

$$\text{买入要「快」} \quad \text{vs} \quad \text{卖出要「慢」}$$

- **底是硬的**：净资产 + 股息托底，跌到极值就是极值，反弹很快 → 该分档买入
- **顶是软的**：利率持续下行会让中枢不断上移（`08-市场风格快照.md` 里银行涨的真正原因是**「无风险利率跌得比它快」**）→ 卖早了会错过整段重估

> 这解释了为什么「均值回归型资产」看起来不涨，实际靠「中枢上移 + 股息复利」赚了很多——**它们的收益不是波动，是漂移**。

## 六、止损：价格不是止损理由，「锚」才是

$$\boxed{\text{均值回归型资产的止损} = \text{锚失效，而不是价格下跌}}$$

| 锚 | 失效信号（才卖） |
|---|---|
| **股息锚** | 分红率下调、取消分红、**分红率 > 100%**（利润撑不住分红）、大股东要求降低分红 |
| **净资产锚** | 大额商誉/资产减值、净资产连续两季下降、PB 跌破净资产且 ROE 转负 |
| **盈利锚** | **ROE 连续 2 个季度下滑 > 2pct**（不是单季波动） |
| **政策锚** | 高速收费年限缩短、电价机制改革、银行息差被强制压缩、机场收费标准下调 |

### 6.1 为什么这条最重要

**如果你用 −10% 价格止损，你会在最低点卖掉最该买的票。**

$$\text{价格下跌} \ \not\Rightarrow \ \text{风险上升}$$
$$\text{对均值回归型资产，价格下跌} \ \Rightarrow \ \text{预期收益上升}$$

**这是与趋势型资产最根本的差别：**

| 资产类型 | 价格下跌意味着 |
|---|---|
| 趋势型 | 判断可能错了 → **该止损** |
| **均值回归型** | **股息率上升、预期收益上升 → 该加仓**（前提：锚没坏） |

> ⚠️ 但这个逻辑**只在锚完好时成立**。所以「检查锚」必须比「检查价格」更频繁。

## 七、两个真实算例

### 7.1 中证银行（2026-11-17）：**已过买点，现在是持有/减仓区**

| 指标 | 数值 | 判读 |
|---|---|---|
| PB | **0.738** | 42/42 破净 |
| 股息率 | **3.94%** | — |
| 10Y 国债（券商测算） | ≈ **1.86%** | → **利差 2.08%** |
| ROE | 9.47% | 隐含 PE 7.79 |
| 息差 | 2026Q2 首次环比回升 1.40% → 1.41% | ✅ 盈利锚稳住 |
| **位置** | **2026-11-17 创 250 日新高** | ⚠️ **不在底部** |

**结论：锚是好的（ROE 止跌、分红 2,600 亿落地），但价格位置已经不在购买区。** 这是「持有 + 吃股息 + 等利差分位回到 80% 以上再加仓」的阶段，不是抄底阶段。

> 🔑 **均值回归型资产的买入机会出现在「创新低」时，不是「创新高」时。** 这是它与趋势型资产最反直觉的差别——**趋势型涨了才买，均值回归型跌了才买。**

### 7.2 福建高速 2026：跌 36% 那一段是不是买点？

| 事件 | 价格 | 该怎么判 |
|---|---|---|
| 年初 | 4.89 | PB 分位（`INDEX.md` 记「历史 41 分位」）→ **不便宜，不买** |
| 跌至 **3.14**（-36%） | 3.14 | ⚠️ **需要验证当时 PB 分位**：若进入 <20% 分位，这就是标准 A 层第 1 档买点 |
| 随后反弹 +19% | ≈3.74 | 均值回归成立 |

**判读要点：**
- 如果 3.14 时 PB 分位确实 <20%，那么这次下跌是**估值回归**（锚没动，价格偏离）→ **该买**
- 如果它跌是因为「收费年限政策变化」或「ROE 跌破 5%」→ **锚失效，不该买**

> 这两种情况价格走势一样、跌幅一样，但一个是机会、一个是陷阱。**区分它们的唯一办法是查锚，不是看图。**

## 八、两种资产的操作对照总表

| 维度 | 趋势型（C 层：科技/主题） | **均值回归型（A 层：红利/类债）** |
|---|---|---|
| 买入信号 | 零轴上方金叉 + 突破前高 | **零轴下方绿柱缩短 + 分位低** |
| 卖出信号 | 红柱见顶 + 跌破 20 日线 | 分位 >80% / 利差分位 <20% |
| **止损依据** | **价格**（$2\sigma_d$） | **锚失效**（ROE/分红/政策） |
| 加仓方式 | 突破加仓（**越涨越买**） | 金字塔分档（**越跌越买**） |
| 交易频率 | 中（一年 3-5 次） | **低（一年 1-3 次）** |
| 收益来源 | 价格差 | **股息 + 中枢上移** |
| 最大风险 | 追高被套 | **价值陷阱（地板下移）** |
| 心理难点 | 怕回调 | **怕越买越跌** |
| 该看的指标 | MACD、成交量、突破 | **PB 分位、股息利差、ROE 趋势** |
