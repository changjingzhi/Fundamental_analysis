# A 股个股基本面与股价走势分析

## 何时使用

- 用户提到某只 A 股并请求"分析""怎么样""能否长期持有""生成报告/文档"；
- 用户给出股票代码（6 位）或名称 + 代码（如"002701 奥瑞金""东方精工 002611"）。

## 执行步骤

### Step 1：解析股票

- 从用户消息或链接（如 `quote.eastmoney.com/sz002611.html`）提取 6 位代码与名称；
- 若只有名称，先通过行情接口确认代码（`fetcher.quote` 需代码，可先用 `https://searchapi.eastmoney.com/api/suggest/get?input=<名称>&type=14` 搜索）。

### Step 2：生成数据底稿

```powershell
$env:PYTHONIOENCODING = 'utf-8'
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
python D:\股票分析\code\a_share_analyzer\main.py <代码> <名称> --out "<输出目录>"
```

- 输出目录建议按日期建文件夹：`D:\股票分析\YYYY_MM_DD_<名称>\`；
- 工具打印控制台摘要；注意 **⚠️ 一次性收益警告**与"扣非 PE"；
- 生成 `<名称><代码>基本面与股价走势分析_底稿.md` 与 `raw_data.json`。

### Step 3：核查关键口径（必做，不可跳过）

1. **归母 vs 扣非**：若最新期归母与扣非差异巨大（如 >50%），必须查明非经常性损益来源——用 `fetcher.announcement_content(art_code)` 阅读业绩预告/年报/出售公告正文；
2. **估值口径**：报告中必须同时呈现"表观 PE(TTM)"与"扣非 PE(TTM)"，并明确说明哪个失真；引用 PB 分位与年度 PB 区间判断真实贵贱，**不因表观 PE 低就称"便宜"**；
3. **重大公告扫描**：核对 4.5 公告扫描列表，对"出售/收购/重组/质押/异动/战略合作"类公告读正文，提炼事件链（时间、对价、影响）；
4. **股本变动**：若每股指标跳变，用 `fetcher.holdernum`/F10 股本历史核对是否由回购注销/增发引起。

### Step 4：完善底稿为最终报告

- 把底稿另存/改名为 `<名称><代码>基本面与股价走势分析.md`；
- 填写全部【待补充】：
  - 公司历史重大事件（并购/暴雷/出售循环等教训）；
  - 财务解读（毛利率趋势、现金流、负债率变化原因）；
  - 主升/主跌段催化事件（结合公告扫描与 K 线月份）；
  - 背离分析：业绩 vs 股价的核心矛盾与反转观察点；
  - 投资要点（积极/风险/综合定位）、适用性矩阵判断、3-5 个可量化跟踪指标、一句话总结。
- 保留八章结构与"八、免责声明"；文末注明数据截至最新交易日、不构成投资建议。

## 写作要求

- 用词客观中性：区分"事实（数据表）"与"推断（分析文字）"；
- 所有数字必须来自底稿/公告，不得编造；引用的催化事件需有公告日期佐证；
- 结论要明确回答用户问题（如"是否适合长期持有"给出类型化判断），但必须声明非投资建议。

## 工具位置
