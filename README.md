# Fundamental_analysis

各行业基本面分析与板块跟踪。

核心理念：**基本面分位 vs 估值分位**。找出「基本面在改善、估值仍在低位」的错配板块，而不是单纯买便宜或买热门。

## 板块清单（申万一级 · 31 个）

按属性分四组，**同属性才能横向比估值**：

- **金融 / 类金融（3）**：银行、非银金融、房地产
- **强周期（6）**：煤炭、石油石化、有色金属、钢铁、基础化工、建筑材料
- **消费（9）**：食品饮料、家用电器、纺织服饰、轻工制造、商贸零售、社会服务、美容护理、农林牧渔、医药生物
- **成长 / 制造（13）**：电子、电力设备、汽车、机械设备、国防军工、计算机、通信、传媒、公用事业、交通运输、建筑装饰、环保、综合

## 分析流程

1. 横向：按属性分组，找同属性可比板块，看谁的**基本面分位在抬升**
2. 纵向：选定板块，套用 `docs/03` 模板填供需、盈利、政策、估值
3. 对估值：比较基本面分位与估值分位，找错配
4. 定验证：写下证伪条件与跟踪日历

## 重要提醒

- **周期股不要用 PE 判断高低**：利润高点 PE 最低、亏损期 PE 失效，看 PB 分位 + 价格历史分位 + 库存。
- **概念板块不能做基本面**：成分重叠、动态调整，只用于主题跟踪。
- **板块属性会迁移**：汽车、电力设备都从成长变成过周期，属性判断错了估值方法就会错。
