## 六、为什么 A 股价值股这么少

| 原因 | 机制 |
|---|---|
| **① ROE 与 PB 的分布错位** | ROE > 15% 的好生意（消费、医药、部分制造）PB 普遍 > 2；PB < 1 的行业恰好是 ROE 下行行业 |
| **② 低 PB 多是「合理折价」而非「错杀」** | 银行息差下行、地产去杠杆、建筑现金流差、钢铁产能过剩 —— 市场对未来 ROE 的定价是准的 |
| **③ 破净门槛的数学约束** | 只有 ROE ≥ 10% 的破净股才是「错杀」，ROE < 8% 的破净股是「应该破净」 |
| **④ 金融股占比过高** | 银行是「高杠杆薄利差」生意，ROE 波动 3%~13%，PB 天然分布在 0.3~1.0，把破净名单填满了 |

## 七、可复用的五条件筛选器

```
PB < 1                ← 价格低于账面（必要条件，非充分条件）
ROE(加权) ≥ 10%       ← 账本能赚钱（超过 PB = 1 的分界线）
扣非同比 > 0          ← 利润没有被侵蚀（排除一次性与恶化）
分红率 > 30%          ← 现金兑现，防止「纸面净资产」
经营现金流 > 0        ← 利润收得回来
```

用这个筛子筛 5,564 只票，**今天只剩 7 只** —— 这就是「A 股有没有价值股」的答案：**有，但稀缺到可以用手指头数。**

## 八、已知局限

- ROE 为 **2026 三季报累计值、未年化**（年化约 ×4/3），跨行业比较需注意报告期口径
- 第 2 步只核实市值前 40 只，剩余小盘未逐只核实
- **未做 PB 历史分位校验**：若某只 PB 处于自身历史 90 分位，则「绝对 PB 低」≠「历史便宜」
- 未纳入分红率、经营现金流两项（需逐只拉分红方案与现金流量表），实际合格数可能**更少**
- 保险股 ROE 分母受准备金与利率假设影响，「低 PB + 高 ROE」不可直接采信
