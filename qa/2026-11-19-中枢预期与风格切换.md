# 问题 1：中枢价格可以计算吗？还是只适合均值回归型（红利）？

## 1.1 能算，但先接受一个事实：算出来的是「区间」

公式在 [`../docs/10-均值回归型资产的买入方法.md`](../docs/10-均值回归型资产的买入方法.md) 已经给出：

$$P^* = \text{合理 PB} \times \text{BPS},\qquad \text{合理 PB} \approx \frac{\text{ROE} - g}{r - g}$$

看起来很精确，但三个输入没有一个是「精确数」：

| 输入 | 从哪来 | 误差来源 |
|---|---|---|
| **ROE** | 财报，可查 | 会用「当期 ROE」高估或低估长期中枢（周期、一次性损益） |
| **r**（要求回报率） | 10Y 国债 + 风险溢价 | **风险溢价是主观的**——市场恐惧时你给 8\%，贪婪时你给 4\% |
| **g**（永续增长） | 历史外推 | 唯一确定的是「它一定不精确」；红利资产 g 取值 0\%~3\%，中枢就上下浮动一大截 |

**所以正确的用法不是「算出 8.37 元，跌到 8.38 就不买」，而是「算出 7.5~9.5 元，跌进下沿开始看」。**

## 1.2 敏感性演示：r 动 1 个百分点，中枢动 20%+

以下为**示例假设**（ROE = 10\%，g = 2\%，仅演示参数敏感度，非真实个股）：

| r（要求回报率） | 合理 PB = (ROE−g)/(r−g) |
|---|---|
| 5.5\% | **2.29** |
| 6.5\% | **1.78** |
| 7.5\% | **1.45** |

$$r: 5.5\% \to 7.5\% \quad \Longrightarrow \quad \text{合理 PB 下降约 } 37\%$$

> 🔑 **结论：公式的主要价值不是给出一个价位，而是告诉你「价格由哪三个变量决定」。你的判断正确与否，取决于对 ROE、r、g 的假设是否比市场更准——而不是公式本身。**

## 1.3 换个方向用：从价格反推「市场在假设什么」

这是公式更实用的用法。银行板块 PB ≈ **0.79**（[`../docs/08-市场风格快照.md`](../docs/08-市场风格快照.md)，2026-11-16 口径）。

若**假设** ROE = 10\%、g = 2\%，反解 r：

$$0.79 = \frac{10\% - 2\%}{r - 2\%} \quad \Longrightarrow \quad r \approx 12.1\%$$

**市场给银行的隐含要求回报率约 12%**——要么市场认为银行的风险溢价极高（坏账、息差），要么市场根本不信 ROE=10\% 能持续（隐含 ROE 更低）。

> 这条反推比正算更有用：**它把「我觉得便宜」变成「我认为市场错了，错在哪个参数上」。** 如果说不清错在哪个参数，就不是「便宜」，只是「价格低」。

## 1.4 适用边界：哪些资产能算，哪些不能

| 资产类型 | 中枢可算性 | 替代方法 |
|---|---|---|
| **红利 / 类债**（银行、高速、港口、运营商、公用） | ✅ **直接可算**——ROE 稳定、g ≈ 0\%~3\%、分红连续 | 公式 + PB 分位 + 股息率利差分位 |
| **强周期**（煤炭、有色、钢铁、化工、航运） | ⚠️ **不算价格中枢，算「中枢盈利能力」** | 用**跨周期平均 ROE / 中枢 EPS** × 合理 PE；且只在周期底部有参考意义 |
| **成长 / 主题**（科技、机器人、创新药） | ❌ **不可算**——$g$ 可以从 0 跳到 100\%，也可从 50\% 掉到 −20\% | 只能用**分位**（我自己历史 PE/PB 区间）和**趋势确认**（右侧） |

**为什么周期股要单独处理**：周期股的「当期 PE 低」往往出现在盈利高点（E 虚高），此时公式里的 ROE 是假的高。所以周期股要先回答「中枢 EPS 是多少」（跨周期平均），再乘合理 PE——这也是 [`../INDEX.md`](../INDEX.md) 里「PE 分位低而 PB 分位高 = 周期顶部低 PE 陷阱」判据的来源。

## 1.5 ⚠️ 两个「中枢」不要混用

| | 估值中枢（本文用的） | 缠论「中枢」 |
|---|---|---|
| 怎么来 | **公式算出来的**（ROE/r/g） | **走势画出来的**（三段重叠的价格区间） |
| 指向 | 未来——「价格应该回到哪」 | 过去——「价格在哪个区间震荡过」 |
| 能否预测 | ✅ 能给出回归方向（前提：假设成立） | ❌ 只能描述已发生的结构，区间突破后失效 |

**唯一共同点：价格围绕它波动。** 但它们回答的是完全不同的问题——看到「中枢」这个词先分清是哪个。

## 1.6 小结

$$\boxed{\text{算得出（ROE/g 稳定）} \Rightarrow \text{量「离中枢多远」};\quad \text{算不出} \Rightarrow \text{量「离分位多远」}}$$

# 问题 2：确定性的事实会影响后续股价吗？还是提前反映？

## 2.1 核心公式：只有「预期差」是新信息

$$\text{新信息量} = \text{事实} - \text{市场预期}$$

- **事实 = 预期** → 新信息量 ≈ 0 → 股价平（甚至「利好出尽」下跌）
- **事实 > 预期** → 上修 → 股价涨
- **事实 < 预期** → 下修 → 股价跌

**所以「股市赚预期的钱」这个说法：对趋势型资产基本成立，对红利型只成立一半。** 下面分开说。

## 2.2 四种典型反应：确定的「好事实」不一定涨

| 情形 | 例子逻辑 | 股价反应 | 时间特征 |
|---|---|---|---|
| **① 超预期** | 季报利润远超一致预期 | 跳空上涨，**随后可能继续漂移**（见 2.4） | 公告日 + 数周 |
| **② 符合预期（且已被抢跑）** | 早已公告的方案（资产注入、分红预案）获批/实施 | **平淡甚至下跌**（买预期、卖事实） | 公告前已涨完 |
| **③ 低于预期** | 京能电力 Q3 单季 **−61.55%**（煤价上行压制，[`2026-11-18-股价为什么会波动.md`](./2026-11-18-股价为什么会波动.md)） | 杀 EPS + 杀估值双杀 | 公告日重定价 |
| **④ 无法提前预期** | 事故、政策突变 | 一次性剧烈重定价 | 事件当日 |

## 2.3 用工作区实例验证：银行 11-16 涨的是什么？

[`../docs/08-市场风格快照.md`](../docs/08-市场风格快照.md) 记录：2026-11-16 中证红利 **+1.42%**、银行Ⅱ **+1.76%**，同日科创50 **−5.16%**。

当天新闻是「21 家银行中期分红超 2600 亿元」。**但分红方案早在半年报时就已公告——「分红事实」不是新信息。**

当天真正被重定价的是：

1. **时点**：分红从「预案」变成「即将到账」，红利资金的再配置需求被激活；
2. **分母**：无风险利率继续下行 → 股息率溢价扩大（3.94\% 股息 vs 无风险利率，溢价 2.08\%）；
3. **相对**：成长端杀跌 → 风险偏好收缩 → 资金搬家（跷跷板）。

$$\text{涨的不是「分红这件事」，而是「分红兑现时点的分母变化」}$$

**这正说明：确定的「好事实」本身不推动股价，推动股价的永远是「相对于预期的变化」。**

## 2.4 为什么「确定性事实」落地后还会继续漂移？

学术界从 1989 年（Bernard & Thomas）起反复记录一个现象：**盈余公告后漂移（PEAD）**——超预期的财报公布后，股价在随后数周至数月仍沿同一方向继续移动。

原因：

| 原因 | 说明 |
|---|---|
| **注意力摩擦** | 信息扩散不均匀：机构先反应，散户后反应，价格分批到位 |
| **卖空/流动性约束** | 利空方向的漂移常被「不愿割肉」心理延长 |
| **确认需求** | 市场需要「第二个季度的确认」才肯给更高估值 |

> ⚠️ 但漂移幅度因股而已（小盘、低关注度、低流动性标的更明显），**不能当作稳定利润来源**——它是「事实确有影响」的证据，不是「随便追都行」的许可。

## 2.5 实操：三步判断「这个事实是否已被定价」

| 步骤 | 看什么 | 结论方向 |
|---|---|---|
| **① 抢跑检查** | 公告前 10~20 日股价与成交量 | 已大涨 + 放量 → 大部分预期已定价 |
| **② 落地检查** | 公告日跳空方向 + 量能 | 高开低走/放量滞涨 → 利好出尽 |
| **③ 反推检查** | 用 1.3 的方法，从当前 PE/PB 反推市场隐含的增长/回报率 | 隐含假设已经很乐观 → 超预期门槛很高 |

## 2.6 两类资产，两种赚钱来源

| | 趋势型（科技/主题） | 均值回归型（红利/类债） |
|---|---|---|
| 赚什么钱 | **预期差**（事实 vs 一致预期） | **兑现 + 时间**（股息到账 + 向中枢回归） |
| 「确定性」的作用 | 确定性高 = 预期差小 = **没肉** | 确定性高 = **锚可靠** = 越跌越敢买 |
| 什么时候卖 | 预期打满（红柱缩短） | 分位 > 80\%（回到中枢上方） |

$$\boxed{\text{趋势型：赚「预期修正」的钱};\qquad \text{红利型：赚「预期早已稳定」的钱}}$$

**「股市赚预期的钱」这句话的完整版是：股价永远在交易预期，只是红利资产的预期稳定到可以用公式锚住，所以能赚「兑现」的钱；趋势资产的预期在持续变化，所以只能赚「修正」的钱。**

# 问题 3：这份筛选清单怎么用？

## 3.1 先说清楚：这 15 行数据不是一个问句，是一张「待考察名单」

它是与 [`../screening/2026-11-17/list.md`](../screening/2026-11-17/list.md) 同一策略的更新版（部分名字重合：南都物业、新亚电子、吉鑫科技、利通电子、盛泰集团、振江股份、亚星锚链、方正科技；也有新面孔：恒丰纸业、长飞光纤、西部矿业、中金公司等）。

**注意一个细节**：同一只票在不同版本里得分会变（方正科技 36 → 41），而现价没变——说明**得分主要由均线/波动等随时间滚动的机械指标驱动，不是基本面变化**。

> 🔑 **所以得分只能用来排序「先看谁」，不能用来判断「买谁」。**

## 3.2 三步漏斗：分类 → 双分位 → 底稿

### 第一步：分类（按主营初判，非结论）

| 类型 | 清单中的名字（初判） | 该用什么工具 |
|---|---|---|
| **周期型** | 恒丰纸业（造纸）、西部矿业（有色）、亚星锚链（造船链）、吉鑫科技（风电铸件）、振江股份（风电结构件）、建发合诚（工程检测）、盛泰集团（纺织出口） | **PB 分位 + 商品/订单周期位置**；⛔ 低 PE 不可信 |
| **成长 / 主题型** | 长飞光纤（光通信）、利通电子（消费电子）、新亚电子（线材）、通达电气（客车零部件）、亚通精工（汽零）、方正科技（PCB） | 趋势确认（右侧）+ 业绩兑现节奏；⛔ 跌幅不是买入理由 |
| **金融** | 中金公司（券商） | **成交额/两融的放大器**，不是红利资产，PB + 市场成交额 |
| **类债候选** | 南都物业（物业费现金流） | 可尝试股息/分红锚，但需先确认分红连续性 |

### 第二步：双分位交叉验证（清单里没有列，必须补）

对每只候选补查：**PE 分位 + PB 分位 + 扣非 PE / PE**。

已验证过的两条判据（来自 [`../INDEX.md`](../INDEX.md) 与 [`../docs/10-均值回归型资产的买入方法.md`](../docs/10-均值回归型资产的买入方法.md)）：

| 判据 | 含义 | 清单内警示对象 |
|---|---|---|
| **PE 分位低 + PB 分位高** | 周期顶部「低 PE 陷阱」 | 西部矿业（清单 PE 8.14，强周期，必须查 PB 分位） |
| **扣非 PE / PE > 1.5** | 利润失真（一次性收益撑 PE） | 逐个核查——清单第 10 列只是简单 PE，未做扣非 |

**利通电子就是现成的反例**：清单里距高点 **−59.4%**，看起来「跌透了」；但 10 文档核实过它 PE 分位 **0%** 的同时 PB 分位 **90.5%**——曾单月 **+126%** 的情绪票，「PE 最低」是因为利润暂时很高，不是价格便宜。

### 第三步：值得进入底稿的，才走完整流程

$$\text{机械清单（数百只）} \rightarrow \text{分类} \rightarrow \text{双分位过滤（数十只）} \rightarrow \text{底稿（个位数）}$$

**清单的正确角色是第一层漏斗，它的产出物是「研究队列」，不是「买入队列」。**

## 3.3 小结

**「跌得多 + 资金流候选」只能证明「值得看一眼」，证明不了任何买入理由。** 买入理由必须来自「位置（分位）+ 劲头（MACD 绿柱）+ 锚（ROE/分红是否稳定）」三件事——而这三件事它一件都没回答。

# 问题 4：怎么判断股票的「风格切换」？

## 4.1 先纠正一个工具错配

**K 线、MACD、成交量都是「时序工具」——描述「一个标的自己怎么走」。而「风格」是「横截面概念」——描述「同一天里谁涨谁跌」。**

用时序工具判断横截面现象，就像用体重秤量身高：**K 线和 MACD 能告诉你「银行自己涨了」，但告诉不了你「银行涨是不是因为成长股在跌」。**

真正能回答「是不是风格切换」的证据，必须**成对出现**：

## 4.2 风格切换的三层证据链

### 第一层：横截面的「单调性」（最强证据）

[`../docs/08-市场风格快照.md`](../docs/08-市场风格快照.md) 的 2026-11-16 就是教科书案例：

| 证据 | 数值 |
|---|---|
| 中证红利 vs 科创50 同日差 | **+1.42\% − (−5.16\%) = 6.58 个百分点** |
| 板块涨跌是否按估值单调排列 | ✅ **PE 最低的银行(+1.76\%)、保险(+1.50\%)、煤炭(+1.22\%)全红；PE 最高的元件(−6.71\%)、人形机器人(−4.11\%)全绿** |

$$\text{风格切换的判据} = \text{同日反向} + \text{按估值单调排列}$$

只满足其一（比如两边都跌、只是跌多跌少）不算切换。

### 第二层：资金结构（确认不是错觉）

| 指标 | 怎么读 |
|---|---|
| **成交额搬家** | 成长板块成交额萎缩、红利板块放大（钱没离场，只是换座位） |
| **融资余额方向** | 融资盘是趋势资金，它退出的方向就是风格冷却的方向 |
| **ETF 申赎** | 宽基/红利 ETF 净申购 = 被动资金也在同向配置 |

### 第三层：持续性（决定「跟不跟」）

08 文档里有一个关键细节：**当天 PB 最低的浦发(+3.65\%、PB 0.47)涨得最多，PB 最高的招行(+1.09\%、PB 0.93)涨得最少。**

$$\text{「填坑式上涨」} \ne \text{「龙头带动」}$$

| 形态 | 内部结构 | 持续性 |
|---|---|---|
| **填坑式**（低估值补涨最多） | 高低切换、抄底资金 | **弱**——补完就停 |
| **龙头带动**（优质股领涨） | 增量资金、趋势资金 | **较强**——有主线 |

**所以判断「切换能否持续」的快速四问**：

1. 切换日附近有无**事件/利率驱动**？（有事件 > 纯情绪）
2. 是**填坑式**还是**龙头带动**？（龙头带动 > 填坑）
3. 资金是**搬家**（一涨一跌）还是**撤离**（同跌）？（搬家可持续，撤离是风险）
4. 是否**连续 3~5 日不反向**？（一日游不算切换）

## 4.3 把你手上的三个工具用对：K 线、MACD、成交量的正确用法

**4.1 说的是「直接拿时序工具判断横截面现象」不行。但把这三个工具「改造」一下，它们全都能用：**

| 你的工具 | 直接用法（错） | 改造用法（对） |
|---|---|---|
| **K 线图** | 看一只股票的 K 线猜「风格要切了」 | **看「指数对」+ 画相对强弱线（RS）** |
| **MACD** | 看一只股票的金叉死叉 | **看两个风格指数的 MACD 是否「同时反向」** |
| **成交量** | 看单只股票放量缩量 | **看成交额在风格之间的「结构占比」** |

### ① K 线 → 相对强弱线（RS）：把横截面问题变成时序问题

$$\text{RS} = \frac{\text{红利指数}}{\text{成长指数}}\quad(\text{例如 中证红利} / \text{科创50})$$

- 把两条指数 K 线**相除**画成一条线：RS 涨 = 红利在跑赢，RS 跌 = 成长在跑赢；
- **RS 线的 20 日均线拐头** = 风格切换的技术信号——这是「你的 K 线工具」判断风格的正确形态；
- RS 创 N 日新高 = 当前风格在加强；RS 贴着均线来回穿 = 拉锯，没有风格。

### ② MACD → 双指数对照：确认切换「已经发生」

风格切换日的 MACD 特征，是**两根柱子同时反向**：

| 红利指数 MACD | 成长指数 MACD | 含义 |
|---|---|---|
| **绿柱缩短** | **红柱缩短** | 资金从成长搬向红利（切换进行中） |
| 红柱增长 | 绿柱增长 | 资金从红利搬向成长 |
| 同向 | 同向 | 不是切换（普涨/普跌） |

✅ [`../docs/08-市场风格快照.md`](../docs/08-市场风格快照.md) 的 2026-11-16：红利 +1.42\% vs 科创50 −5.16\%（差 6.58pp）——当天两根柱子几乎必然反向。

⚠️ 两条纪律：

- **日线 MACD 对切换太灵敏**（噪声多），判断风格用**周线**更稳；
- MACD 是**确认工具、不是预测工具**——它告诉你「切换已经在发生」，不告诉你「还能持续多久」。

### ③ 成交量 → 看结构占比，不看单票总量

| 观察 | 怎么算 | 读法 |
|---|---|---|
| **资金是搬家还是离场** | 两市总成交额 + 红利板块成交额占比 | 总量平、红利占比升 = **存量搬家**；总量放量、占比升 = **增量进场** |
| **切换强度** | 红利/成长成交额之比是否连续 N 日上升 | 连续上升 = 趋势资金在跟 |
| **涨停结构** | 涨停家数里红利类 vs 题材类的占比 | 题材涨停多 = 情绪在成长侧，反之亦然 |

> 🔑 **判据：总成交额没放大而占比单日跳变 → 多半是「跷跷板式存量搬家」，持续性弱；总量放大 + 占比持续上升 → 增量资金，持续性强。**

### 4.3.1 检查清单（照着做就能跟上 08 文档的分析节奏）

| 频率 | 检查项 | 判定标准 |
|---|---|---|
| **每日 5 分钟** | ① 中证红利与科创50 涨跌差 | 同日反向 > 2pp = 候选切换日 |
| | ② RS 线（红利/科创50）的 20 日均线方向 | 拐头 = 技术确认 |
| | ③ 两市成交额 + 红利成交额占比 | 判断「搬家」还是「撤离」 |
| | ④ 连续反向天数 | ≥ 3 日才算切换 |
| **每周** | ⑤ 双指数**周线** MACD 柱方向 | 同时反向 = 中级风格切换 |
| | ⑥ 板块涨跌是否按估值单调排列 | 08 文档式验证（PE 最低的全红？） |

## 4.4 为什么不建议「预测」风格切换

[`../docs/12-板块关联与轮动.md`](../docs/12-板块关联与轮动.md) 给出的轮动时间尺度：

| 轮动层 | 时间尺度 | 可预测性 |
|---|---|---|
| 盈利周期轮动 | 2~4 年 | 可跟踪（看 PB 分位 + 商品价格） |
| **估值风格轮动** | **3~12 个月** | **部分可判断（本文三层证据）** |
| 情绪主题轮动 | 1~8 周 | **基本不可预测** |

**风格切换属于中间层：能做「确认 + 跟随」，做不了「提前预测」。**

可行的替代做法不是猜切换，而是：

$$\text{不预测风格} \Rightarrow \text{A 层（红利）吃锚、C 层（趋势）只做右侧确认后跟进}$$

**这正好回到你说的「只赚确定能赚的钱」——它的操作定义是：只做「可测量」的机会。**

| 可测量 | 不可测量 |
|---|---|
| 位置（PE/PB 分位） | 明天涨不涨 |
| 劲头（绿柱连续缩短几天） | 风格什么时候切 |
| 利差（股息率 − 无风险利率） | 情绪顶部在哪 |

# 问题 5：心态——「破山中贼易，破心中贼难」

这条不是技术问题，但值得留一句可操作的话：

**「相信自己」的正确形式是「相信事先写下的规则」。**

| 做法 | 为什么有用 |
|---|---|
| 每次买卖**事前**写下：依据（分位/柱状/利差）+ 证伪条件 | 事后才能区分「判断错」和「运气差」 |
| 事后只问一个问题：**当时依赖的那个变量变了吗？** | 变量没变 = 波动，拿住；变量变了 = 判断错，认错 |
| 结论不回改，只追加 | 回改会抹掉唯一能校准自己的证据 |

> **心性的修炼不在于「不犯错」，而在于把每一次犯错变成规则库的一条记录。** 规则错了可以改，情绪错了只能亏。

# 问题 6：MACD 和红利的手法为什么不一样？为什么判断走势这么耗心力？

## 6.1 不是「不一样」，是「方向相反」

[`../docs/11-一页图解两套买卖逻辑.md`](../docs/11-一页图解两套买卖逻辑.md) 的核心结论：

| | 趋势型（科技/主题） | 均值回归型（红利/类债） |
|---|---|---|
| 看哪个柱 | 红柱（上涨动能） | **绿柱（下跌动能）** |
| 买入 | 红柱**开始变长** | **绿柱开始缩短**（且 DIF 在零轴下方深处） |
| 卖出 | 红柱**开始缩短** | 绿柱开始变长（且分位 > 80\%） |
| 本质 | 顺势追涨 | **逆势抄衰竭** |

**同一张 MACD 柱状图，两套规则完全镜像。** 用红利的手法做科技，或反过来，都会系统性做反。

## 6.2 为什么判断走势「很耗费心力」——三个原因

| 原因 | 表现 | 解法 |
|---|---|---|
| **工具错配** | 用「趋势的眼光」盯红利资产：每天绿柱一根根看，越看越慌（其实你只需要看它「有没有在缩短」） | 按资产类型选规则（6.1 表），不混用 |
| **决策频率过高** | 日线盯盘 × 全仓 → 每个小波动都要求你决策一次 | **A 层按周看、C 层按日看**；层级对应频率 |
| **「判断」代替「测量」** | 用预测姿势面对不可预测的事（风格何时切、明天涨不涨） | 只测量可测量项（4.3 表），判断频率降为零 |

$$\text{心力消耗} \approx \text{决策频率} \times \text{不可判断事物的占比}$$

**把不可判断的比例降下来，心力自然省下来——这就是「只赚确定能赚的钱」在心理层面的等价说法。**
